# Davincha Slug

Run & gun 2D estilo *Metal Slug*, ambientado en el lejano oeste (año 1881: fiebre
del oro, caravanas de ganado y el ferrocarril de hierro). Davincha se enfrenta a
la banda del Cráneo Rojo a lo largo de 6 misiones, cada una con su propio jefe.

Es un archivo HTML autocontenido (canvas + JS vanilla, sin dependencias ni build):
basta con abrir `index.html` en un navegador.

## Misiones

1. Pueblo Fronterizo — jefe: El Sheriff Corrupto
2. El Cañón Seco — jefe: El Artillero del Cañón
3. La Mina del Diablo — jefe: El Gólem de la Mina
4. El Rancho en Llamas — jefe: El Jinete Fantasma
5. El Expreso Fantasma — jefe: La Locomotora Maldita
6. El Fuerte del Cráneo Rojo — jefe final: El Cráneo Rojo

## Controles

| Acción | Teclado |
|---|---|
| Moverse | Flechas ◀▶ o A/D |
| Apuntar arriba | Flecha ▲ o W |
| Agacharse | Flecha ▼ o S |
| Saltar | Z o espacio |
| Disparar | X |
| Lanzar dinamita | C |
| Pausa | P o Esc |

En móvil aparece un D-pad y botones táctiles en pantalla.

## Mecánicas

- Corazones de vida + vidas extra, con "continuar" al perderlas todas.
- Armas: Colt (munición infinita), escopeta y rifle (munición limitada, se
  recogen en cajas), más dinamita de área.
- Enemigos: pistoleros, escopeteros, francotiradores, dinamiteros, jinetes a
  caballo y torretas fijas, más barriles explosivos.
- Rehenes para rescatar (bonus de puntos) y un jefe único por misión con
  segunda fase al 50% de vida.
- Sonido y música procedurales (Web Audio), sin archivos de audio externos.
