# Fernando Sánchez — landing page

Landing page de una sola página para Fernando Sánchez, chef especializado en pizza napolitana y masas caseras. Proyecto estático (HTML/CSS/JS, sin build ni dependencias), independiente del bot P2P del resto del repo.

## Ver en local

Abrí `index.html` directo en el navegador, o serví la carpeta:

```bash
cd website
python3 -m http.server 8000
```

Y entrá a `http://localhost:8000`.

## Qué es real y qué es de ejemplo

- **Fotos** (`assets/images/`): las 5 que se compartieron (masa cruda, barnizado, pan horneado, burger de autor y foto del chef).
- **WhatsApp e Instagram** (sección de contacto y footer): son los datos reales que se pasaron (`wa.me/5493835525485`, `@szfer22`).
- **El resto del texto** (bio, especialidades, estadísticas "100% / 24–48h / 0 atajos") es contenido inventado a modo de propuesta, como pidió el usuario, para dar una idea de estructura y tono. Conviene revisarlo con Fernando y ajustarlo antes de publicarlo.
